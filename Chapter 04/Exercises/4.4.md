## Exercise 4.4

**Question:**
*Remember binary search from chapter 1? It's a D&C algorithm, too. Can you come up with the base case and recursive case for binary search?*

**Answer:**
*Yes.* 
1. The base case is: 
    1. Case A (Found): If `list[mid] == target`, the target is found in the `mid` position
    2. Case B (Not Found): If `low > high`, then the target is not available in the list
2. The recursive case: 
    * If the item is less than `list[mid]`, you search the left half of the list (by changing `high = mid - 1`.
    * If the item is greater than `list[mid]`, you search the right half of the list (by changing `low = mid + 1`.
